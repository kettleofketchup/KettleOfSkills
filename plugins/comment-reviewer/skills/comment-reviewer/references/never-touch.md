# Never touch — both tiers

Precedence: **mechanical never-touch → commented-out code → judgment never-touch.** Any skip
in either tier beats every comment class — a span matching both a never-touch entry and a
Class A tell-tale (`// NOTE: as requested by the security review, retry twice`) is never
touched.

## Mechanical tier — enforced by `extract_comments.py`, not the agent

The extractor already decided these; the agent's job is only to **report the exact reason
string** it emits, never to re-derive the rule. The strings, verbatim from
`scripts/extract_comments.py`:

| Reason string | What it means |
|---|---|
| `position-locked` | in the first two lines of the file — shebangs, `#!nix-shell` continuations, PEP 263 encoding lines, Ruby magic comments, Dockerfile `# syntax=`/`# escape=`/`# check=`, vim/emacs modelines |
| `directive` | read by a compiler, bundler, linter, or database — lint/format/coverage suppressions (`nolint`, `noqa`, `eslint-disable`, `pragma: no cover`, …), codegen markers (`+kubebuilder`, `+goose`, `//go:embed`, `//export`), `sourceMappingURL`, JSX/Flow/TS pragmas, SQL `/*! */` and `/*+ */` |
| `licence` | licence headers, SPDX identifiers, copyright blocks |
| `test-oracle` | doc comment containing `>>>`, a code fence, `.. code-block::`, `// Output:`, `# Output:`, `Usage:`, or `@example` — its text is compared by a test runner |
| `protected-prefix` | comment body starts with `NOTE`, `WARNING`, `CAUTION`, `SAFETY`, `HACK`, `XXX`, `FIXME`, or `TODO` |
| `excluded-path` | file lives under a skip directory (`vendor/`, `node_modules/`, `testdata/`, `fixtures/`, `migrations/*.sql`, …) or matches a skip filename pattern (`*.min.js`, `*_pb2.py`, `*.proto`, lockfiles, …) |
| `generated` | a generated-file marker (`@generated`, `Code generated`, `DO NOT EDIT`, `<auto-generated>`) appears in the first 30 lines |

A span carrying any of these reasons is not a candidate for Class A/B/C at all — do not judge
it, just count it in the report.

Six whole-file skip reasons exist alongside these but never reach comment-level judgment
either — enumerated in full, since this table's whole value is being exhaustive:

| Reason string | Fires when |
|---|---|
| `markdown-out-of-scope` | suffix is `.md`, `.markdown`, or `.mdx` |
| `multi-language-unsupported` | suffix is `.vue`, `.svelte`, or `.astro` — per-block token selection is not implemented |
| `unreadable` | the file cannot be read (`OSError` on open) |
| `too-large` | file exceeds the 1 MB size ceiling |
| `binary` | a NUL byte appears in the first 8 KiB |
| `unknown-language` | the extension is not in the language table and no recognized shebang is present |

**Preserved byte-for-byte, including whitespace.** golangci-lint honours `//nolint:` only with
no space after the slashes — a Class C spacing tidy on a `directive` span would silently
disable the suppression and break the build on the original lint it was guarding against.

## Judgment tier — requires reading, lives here because the extractor can't decide it

- **Doc comments whose structure is load-bearing:** godoc first-word convention, rustdoc
  intra-doc links, Sphinx directives, JSDoc and Doxygen tag blocks. Reformatting the prose is
  fine; breaking the structural convention is not.
- **Commented-out code** — report, never delete. This is a **mechanical tiebreak, tested
  before Class B**: the body lexes as a statement, or contains an assignment, a call with
  parentheses, a block delimiter, or a keyword in statement position. Mixed prose and code
  counts as code. A comment that is 90% explanation and one trailing code fragment still
  routes here, not to Class B or C.
- **Protected prefixes** at judgment time, not just extraction time: a comment whose first
  token is `NOTE`, `WARNING`, `CAUTION`, `SAFETY`, `HACK`, `XXX`, or `FIXME` is never deleted —
  it is only condensable, and only under Class C's no-loss test.
- **TODOs carrying an issue link** (`// TODO(#412): …`, `// TODO: JIRA-991 …`) are never
  deleted regardless of whether the described work looks done — the link is the traceability
  Class A must not destroy.
- **Translator and i18n notes** (`// i18n: this string uses the casual register`) — never
  rewritten or condensed; they are instructions to a translator, not documentation of the
  code.

See `comment-classes.md` for what happens to a span once it clears both tiers, and
`rewrite-guidelines.md` for how a permitted rewrite is actually produced.
